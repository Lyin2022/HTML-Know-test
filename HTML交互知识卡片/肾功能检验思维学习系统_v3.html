肾功能检验
三维定位思维

从"产生端 vs 排泄端"两条链切入，逐层锁定病变部位与功能，把零散指标串成可执行的判读路径。

学习路径

核心框架：每个指标从两条链解释

排泄端：能不能顺利排出？排不出是肾前（血供不足）还是肾脏本身（哪个部位、哪项功能受损）？
产生端：产生过多或不足——来自非肾脏疾病或生理因素（饮食、肌肉量、代谢、妊娠等）。这是真实存在的指标改变，并非"假象"，只是病变不在肾脏本身。
每条目标注关联强度：实心点=高关联（直接指向肾病）/ 灰点=中关联（需鉴别）/ 浅点=低关联（多为生理/外因，非肾病变）。

任一肾功能指标异常
↓
① 第一问：产生端（非肾/生理因素）正常吗？摄入 · 代谢 · 合成 · 肌肉量
产生端改变（非肾/生理因素）
肉食/运动→Scr↑；消瘦肌少→Scr↓（掩盖肾功能！）；高蛋白饮食/消化道出血→BUN↑；化疗细胞分解→UA↑；妊娠→eGFR↑。
这些是生理或非肾疾病的真实指标改变，并非假象；先识别来源，避免误判为肾病或漏诊肾性异常。
产生正常 → 进入下一问
确认无饮食、运动、肌肉量、妊娠等干扰后，进入排泄端分析。
↓
② 第二问：排不出去，堵在哪一环？
肾前性（血送不到肾脏）
脱水、休克、心衰 → 肾灌注↓ → 滤过↓。
特征：BUN/Scr 比值↑；Scr 一过性升高，补液后回落。可逆，非肾本身病变。
肾性（肾脏本身坏了）→ 进入第三问
肾小球实质损伤 / 肾小管间质病变 / 肾血管病变，需进一步定位部位与功能。
肾后性（尿排不出去）
结石、前列腺增生、肿瘤压迫 → 排尿受阻 → 逆压→滤过↓ → BUN、Scr↑。
常伴尿量骤减、肾积水（超声确诊），解除梗阻后回落。
↓（确认为肾性）
③ 第三问：哪个部位、哪项功能坏了？
肾小球 · 滤过功能
组合：Scr↑ + BUN↑ + eGFR↓（同步异常，比值正常）。
疾病：急慢性肾小球肾炎、慢性肾衰竭、多囊肾、糖尿病肾病。
信号：eGFR 一过性↑ = 高滤过（早期糖肾/妊娠）。
肾小管 · 浓缩稀释
组合：尿比重持续↓ + 夜尿增多 + 尿渗透压↓。
疾病：慢性间质性肾炎、药物性肾损伤（NSAIDs 等）、慢性肾衰、尿崩症。
要点：夜尿增多常是最早主诉，最易忽略。
肾小管 · 重吸收
组合：血糖正常 + 尿糖阳性（肾性糖尿）。
疾病：间质性肾炎、Fanconi 综合征、药物性损伤。
要点：尿糖(+)必须核对血糖！重吸收环节"金标准探测点"。
肾小管 · 分泌排泄
组合：尿酸↑（无饮食因素）、顽固性低钾/代谢性酸中毒。
疾病：尿酸排泄障碍型高尿酸、肾小管酸中毒。
要点：UA↑需常规核对全套肾功能（双向思考）。
↓
④ 溯源：用药史（氨基糖苷/造影剂/NSAIDs）、脱水、基础病（糖尿病/高血压）
⑤ 动态观察：晚期常"球管同损"，需动态追踪

总结概括总表

肾功能核心指标速查（关联度：实心=高 / 灰=中 / 浅=低；"产生端"指非肾脏来源的生理/疾病因素）
指标部位/功能升高原因降低原因关联度易错要点
Scr 肌酐肾小球·滤过 ↑ 产生：肉食/剧烈运动/横纹肌溶解
排泄：肾前(脱水) / 肾性(肾炎、肾衰) / 肾毒性药物		 ↓ 消瘦老年、肌少症、恶病质、妊娠稀释 高 正常≠肾功能正常（滞后+肌肉量干扰）；eGFR 优先
BUN 尿素氮肾小球滤过+灌注 ↑ 产生：高蛋白饮食/消化道出血/烧伤感染
排泄：肾前性(最常见) / 肾性 / 肾后梗阻		 ↓ 低蛋白饮食、重度肝衰、妊娠 中 特异性低！单看 BUN 不能诊断；BUN/Scr 比值是关键
eGFR整体滤过水平 ↑ 妊娠 / 早期糖肾高灌注 / 剧烈运动 ↓ 肾性：肾小球减退、CKD / 肾前灌注不足 / 高龄生理性 高 早于肌酐异常，优先参考；升高≠肾功能好
UA 尿酸肾小管·分泌排泄 ↑ 排泄：肾功能减退
产生：高嘌呤饮食/饮酒/化疗分解
双向恶性循环：肾↓→UA↑→结晶沉积→伤肾		 ↓ 严重肝损 / 营养不良 / 小管重吸收障碍 高 UA↑ 必须常规核对肾功能，双向思考
尿比重肾小管·浓缩 ↑ 肾外脱水浓缩 / 急性肾炎少尿代偿 ↓ 浓缩功能丧失：间质性肾炎、药物损伤、慢性肾衰、尿崩症 高 持续低比重尿+夜尿增多 = 小管受损典型表现
尿渗透压肾小管·浓缩稀释 ↑ 脱水、容量不足 ↓ 浓缩衰竭：慢性间质性肾病 高 精准度高于尿比重，用于疑难鉴别
尿糖
(肾性糖尿)		肾小管·重吸收 血糖正常 + 尿糖阳性 → 重吸收功能丧失（间质性肾炎、药物损伤） 高 尿糖(+)必须核对血糖，勿盲判糖尿病

口诀速记

① 看来源：产生多了还是少了？肉食、肌少、饮食、妊娠等属非肾脏来源的真实改变，先识别再判断是否为肾性异常。
② 看通路：肾前（灌注不足，比值↑）、肾后（梗阻）、肾本身？
③ 看部位：小球坏（Scr/BUN/eGFR）还是小管伤（比重/尿糖/渗透压）？
④ 看功能：滤过、重吸收、浓缩稀释、分泌——四工位逐一排查
⑤ 看联动：晚期球管同损，动态追踪 + 溯源用药史/基础病
